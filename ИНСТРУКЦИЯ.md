# Универсальная форма расчёта буровзрывных работ (БВР)

Система расчёта БВР и формирования проекта массового взрыва. Состоит из двух
платформ с единой расчётной моделью: **веб-форма** и **Telegram-бот**.

Расчётная модель перенесена из рабочей книги «Проект БВР.xlsm» и сверена
с эталоном — расхождение не превышает 0,1 % (связано с артефактом круговой
ссылки в исходной Excel-книге; в форме используется строгая забойка 2 м).

## 1. Веб-форма

### Запуск
Дважды щёлкните файл **`Форма_расчёта_БВР.html`** — он откроется в браузере
(Chrome, Edge, Yandex). Установка не требуется. Нужен доступ в интернет
(подгружаются библиотеки чтения PDF и экспорта Excel).

### Порядок работы
1. **Параметры** — общие сведения и параметры БВР. Расчётные поля
   (температура, плотность ДТ, расстояние между рядами) заполняются
   автоматически.
2. **Зарядная карта** — задайте число рядов и скважин, введите проектную
   глубину каждой скважины. Пустая ячейка — скважина отсутствует.
3. **Паспорт БВР** — загрузите паспорт в формате PDF. Форма извлекает
   доступные текстовые данные (месторождение, блок, горизонт) и прикладывает
   файл к проекту.
4. **Расчёт** — результаты считаются автоматически.
5. **Проект** — нажмите «Сформировать проект»: формируется проект массового
   взрыва из 16 разделов (обложка, акт, распорядок, таблица, листы инструктажа,
   приказ, расчёты, безопасные расстояния).
6. **Подтверждение** — поставьте отметку подтверждения, затем:
   - **Распечатать проект** — печать;
   - **Экспорт в Excel** — выгрузка расчётов в `.xlsx`;
   - **Сохранить в PDF** — в окне печати выберите принтер «Сохранить как PDF».

## 2. Telegram Mini App + бот

Основной сценарий работы в Telegram:

1. Пользователь отправляет боту `/start`.
2. Бот показывает кнопку **«Открыть форму БВР»**.
3. В Telegram открывается мини-приложение с формой, похожей на веб-версию.
4. После отправки формы бот принимает параметры и зарядную карту.
5. Бот просит загрузить паспорт БВР в PDF или отправить «-».
6. После подтверждения бот формирует и присылает **Excel и PDF** проекта.

> Важно: Telegram Mini App открывается только по HTTPS-ссылке. Покупать домен
> не нужно: используется бесплатный GitHub Pages для публичного репозитория.
> Для репозитория `AlexeiShirobokov/BVR` адрес Mini App после включения Pages:
> `https://alexeishirobokov.github.io/BVR/`.

### Размещение Mini App на GitHub Pages

1. Создайте репозиторий на GitHub: `AlexeiShirobokov/BVR`.
2. Загрузите в него весь проект.
3. В GitHub откройте **Settings → Pages**.
4. В **Build and deployment** выберите:
   - Source: **Deploy from a branch**;
   - Branch: `gh-pages`;
   - Folder: `/ (root)`.
5. Сохраните настройки и дождитесь публикации.
6. Используйте ссылку:

```text
https://alexeishirobokov.github.io/BVR/
```

### Установка
Нужен Python 3.10 или новее.

```bash
cd telegram_bot
pip install -r requirements.txt
```

### Создание бота
1. В Telegram откройте **@BotFather**, команда `/newbot`, получите токен.
2. Задайте токен переменной окружения:

```bash
export BVR_BOT_TOKEN="ваш_токен_от_BotFather"      # Linux / macOS
set BVR_BOT_TOKEN=ваш_токен_от_BotFather           # Windows
```

3. Задайте HTTPS-адрес мини-приложения:

```bash
export BVR_WEBAPP_URL="https://alexeishirobokov.github.io/BVR/"   # Linux / macOS
set BVR_WEBAPP_URL=https://alexeishirobokov.github.io/BVR/        # Windows
```

### Запуск
```bash
python bot.py
```

### Работа с ботом
- `/start` или `/form` — открыть кнопку мини-приложения;
- `/dialog` — запасной пошаговый ввод в чате;
- в Mini App заполняются параметры и зарядная карта;
- после отправки формы паспорт БВР загружается PDF-файлом (необязательно);
- после подтверждения бот присылает готовый проект — **Excel и PDF**;
- `/cancel` — отмена, `/help` — справка.

## Расчётная модель

Реализованы формулы из листов «Параметры», «Каталог скважин», «Зарядная карта»
и расчётных листов 12–17 книги «Проект БВР.xlsm»:

- расход селитры на 1 п.м, выход горной массы, удельный расход ВВ;
- ЛСПП, коэффициент сближения зарядов, сеть бурения;
- объём массива, средние глубина / высота уступа / перебур / заряд / забойка;
- масса ВВ (аммиачная селитра, дизтопливо, ПТ-П-2250), средняя масса заряда;
- средства инициирования (Искра-С, Искра-П 42/67 мс, Искра-В);
- безопасные расстояния: по разлёту кусков, УВВ, сейсмике, высоте разлёта;
- итоговые радиусы опасной зоны для людей и оборудования.

## Ограничения

Паспорт БВР — это чертёж (растровая графика), поэтому таблица глубин скважин
из PDF автоматически **не распознаётся**. Извлекаются только текстовые
сведения (месторождение, блок, горизонт), сам файл прикладывается к проекту.
Зарядную карту вводите вручную либо по данным паспорта.
